# Laravel Setup Utility

A standalone, disposable Laravel ecosystem configurator.

## Status

Architecture approved; CLI packaging foundation in progress. Application installation is not implemented yet.

## Direction

- CLI-first with a shared inspect, plan, apply and verify engine.
- Only selected application packages and configuration remain in targets.
- Stable and dev recipe catalogs pinned per run.
- Conservative additive support for existing applications.
- Temporary browser interface, SaaS/tenancy and optional AI recommendations follow the core CLI.

Track delivery in [GitHub Issues](https://github.com/boncanca/LaravelSetupUtility/issues). The first increment is [standalone CLI and PHAR packaging](https://github.com/boncanca/LaravelSetupUtility/issues/1).
